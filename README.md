# IBM Data Science Professional Certificate - Course-6-7-8 Portfolio 🎓

This repository contains the three major case studies completed during the IBM Data Science Professional Certificate. It demonstrates an end-to-end data workflow: **Database Querying $\rightarrow$ Predictive Modeling $\rightarrow$ Interactive Visualization.**

## 📂 Project Index

### 1. [Chicago Crime & Socioeconomic Analysis](./01-Chicago-SQL-Analysis)
* **Skill:** Database Engineering (SQL)
* **Goal:** Identifying the link between poverty levels and crime rates in Chicago using Joins, Aggregations, and Sub-queries.

### 2. [Seattle Housing Price Prediction](./02-Housing-Price-Prediction)
* **Skill:** Machine Learning (Regression Analysis)
* **Goal:** Building a Pipeline (Scaling + Polynomial Features + Ridge Regression) to predict housing prices with **75% accuracy ($R^2$)**.

### 3. [Automotive Recession Impact Dashboard](./03-Automotive-Recession-Analysis)
* **Skill:** Data Visualization (Dash/Plotly)
* **Goal:** A deployed web application visualizing how historical recessions impacted automobile sales trends by vehicle category.
